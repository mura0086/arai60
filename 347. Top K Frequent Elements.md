# 347. Top K Frequent Elements

## STEP1
- 何もみずに解いてみる
```text
各要素と出現回数の対応付けをマップで管理
それを最大heapに入れてtopをk回vectorにうつす
としたかったが、heapでpair型が使えるかどうか
どのように使えるかと調べているとタイムリミット
答えをみた
```
```cpp
class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) {
        map<int, int> frequency;
        priority_queue<pair<int,int>> heap;
        for (int num : nums) {
            frequency[num]++;
        }
        for (auto freq : frequency) {
            heap.push({freq.second, freq.first});
        }
        vector<int> ans;
        while (ans.size() < k && !heap.empty()) {
            ans.push_back(heap.top().second);
            heap.pop();
        }
        return ans;
    }
};
```

#### 感想
```text
priority_queueではpairを利用する場合
pairのfirstをキーとして順序付けするようだった
mapのsecond,firstを入れ替えたりしているところを変数に置いたほうが
わかりやすか
諸々の変数が気になる
```

## STEP2
### プルリクやドキュメントを参照
- 最小heapを利用することで
- heapにpushしていくところでheapがk個以上ならpop
- これによりheapが空になるまでvectorに移すという条件にできる
- for文でmapのkeyとvalueを変数においていた
- 未使用の変数を__maybe_unusedとしていた

```cpp
class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) {
        map<int, int> num_to_freq;
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> top_k_nums;
        for (int num : nums) {
            num_to_freq[num]++;
        }
        for (auto [num, freq] : num_to_freq) {
            top_k_nums.push({freq, num});
            if (top_k_nums.size() > k) {
                top_k_nums.pop();
            }
        }
        vector<int> top_k_num;
        while (!top_k_nums.empty()) {
            auto [__maybe_unused, num] = top_k_nums.top();
            top_k_num.push_back(num);
            top_k_nums.pop();
        }
        return top_k_num;
    }
};
```


#### 感想
```text
動きのイメージがしやすく、無駄にheapへpushすることがなくなった
実際に手作業するとしたらこちらの動きになると思う
```
