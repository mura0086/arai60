## STEP2
### プルリクやドキュメントを参照
- 有効な入力をsetで用意
- 各種bracketの対応づけをmapで行う
- 変数名の変更
- 想定しない入力が来た場合の処理

```cpp
class Solution {
public:
    bool isValid(string s) {
        set<char> valid_input = {'(', ')', '{', '}', '[', ']'};
        map<char, char> open_to_close = {{'(',')'},{'{','}'},{'[',']'}};
        stack<char> open_brackets;
        for (char character : s) {
            if (valid_input.find(character) == valid_input.end()) {
                continue;
            }
            if (open_to_close.find(character) != open_to_close.end()) {
                open_brackets.push(character);
            } else if (!open_brackets.empty() && character == open_to_close[open_brackets.top()]) {
                open_brackets.pop();
            } else {
                return false;
            }
        }
        return open_brackets.empty();
    }
};
```
* 有効な入力でない場合、何もしない
* 現在の文字が開き括弧の場合スタックに追加
* スタックが空でなく、スタックの一番上と現在の文字が一致していたらスタックからpop
* 最後まで処理したうえでスタックが空でなければtrue、そうでなければfalseを返す
