# 206. Reverse Linked List

## STEP1
- 何もみずに解いてみる

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        stack<int> node_list;
        ListNode *node = head;
        ListNode dummy;
        ListNode *reverse_list = &dummy;
        while (node) {
          node_list.push(node->val);
          node = node -> next;
        }
        while (!node_list.empty()) {
            reverse_list->next = new ListNode(node_list.top());
            node_list.pop();
            reverse_list = reverse_list->next;
        }
        return dummy.next;
    }
};
```
#### 考えたこと
* stackに順番通りいれていく
* stackの一番上から取り出して新しいリストノードをつないでいく

#### 感想
* スタック以外のやりかたもいくつかありそう
* 変数名がきになる

## STEP2
### プルリクやドキュメントを参照
* そのままリストノードをつなぎ変えるやりかたと再帰があるよう

#### 繋ぎ変え
```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode *reverse_node = nullptr;
        ListNode *original_node = head;
        while (original_node) {
            ListNode *next_node = original_node->next;
            original_node->next = reverse_node;
            reverse_node = original_node;
            original_node = next_node;
        }
        return reverse_node;
    }
};
```
#### 再帰

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        return reverseListHelper(head, nullptr);
    }
private:
    ListNode* reverseListHelper(ListNode *current_node, ListNode *reverse_node) {
        if (current_node == nullptr) {
          return reverse_node;
        }
        ListNode *next_node = current_node->next;
        current_node->next = reverse_node;
        return reverseListHelper(next_node, current_node);
    }
};
```

#### 感想
* 繋ぎ変えの解法が簡潔で動きもイメージしやすかった。
* 複数の選択肢があるとき選んだ根拠をもてるようになりたい。
