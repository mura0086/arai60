# 387. First Unique Character in a String

## STEP1
```text
何もみずに5分以内に解いてみる
```
#### 考えたこと
```
文字毎に出現位置と出現回数を記録。
出現回数が１のものでもっとも出現位置が早いものを調べる
```
```cpp
class Solution {
public:
    struct PositionToCount {
        int position, count;
    };
    int firstUniqChar(string s) {
        map<char, PositionToCount> lower_alphabet_to_position_to_count;
        for (int i = 0; i < s.size(); i++) {
            lower_alphabet_to_position_to_count[s[i]].position = i;
            lower_alphabet_to_position_to_count[s[i]].count++;
        }
        int position_of_first_unique_character = INT_MAX;
        for (const auto& [_, position_to_count] : lower_alphabet_to_position_to_count) {
            if (position_to_count.count == 1) {                
                position_of_first_unique_character = min(position_of_first_unique_character, position_to_count.position);
            }
        }
        if (position_of_first_unique_character != INT_MAX) {
            return position_of_first_unique_character;
        } else {
            return -1;
        }
        
    }
};
```
#### 感想
```text
2回以上出てきた文字も含めて走査する必要がない
```

- 文字の出現回数のみキープしておいて、再度全体走査①
- 出現回数が１の初めに出てきた文字を返せば無駄がない
- queue,stackを用いる方法が直感的で無駄がなくよいと思った②
- LRUcache（Least Recently Used）について
- vectorにいれて文字をキーにsortする方法もあるようだったが
- 少し読みづらく好みではなかった

①
```cpp
class Solution {
public:
    int firstUniqChar(string s) {
        map<char, int> character_to_count;
        for (int i = 0; i < s.size(); i++) {
            character_to_count[s[i]]++;
        }
        for (int i = 0; i < s.size(); i++) {
            if (character_to_count[s[i]] == 1) {                
                return i;
            }
        }
        return -1; //Not Found
    }
};
```
②
```cpp
class Solution {
public:
    struct CharacterAndIndex {
        char character;
        int  index;
    };
    int firstUniqChar(string s) {
        map<char, int> character_to_count;
        queue<CharacterAndIndex> character_to_index;
        for (int i = 0; i < s.size(); i++) {
            character_to_count[s[i]]++;
            character_to_index.push({s[i], i});

            while (!character_to_index.empty() && character_to_count[character_to_index.front().character] >= 2) {
                character_to_index.pop();
            }
        }
        if (!character_to_index.empty()) {
            return character_to_index.front().index;
        }
        return -1; //Not Found
    }
};
```
#### 感想
```text
①のコードは簡潔でよいと思った
O(n log k)
②はone passで直感的にわかりやすい
O(n)
```
