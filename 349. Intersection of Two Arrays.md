# 349. Intersection of Two Arrays

## STEP1
```text
何もみずに5分以内に解いてみる
```
#### 考えたこと
```
nums1に存在している数字をチェック
nums2でnums1にでチェック済みなら別途チェック
mapであればキー昇順になるのでそのままvectorを用意して入れる
```
```cpp
class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
        map<int, int> num_to_count;
        for (int num1 : nums1) {
            num_to_count[num1] = 1;
        }
        for (int num2 : nums2) {
            if (num_to_count[num2]) {
                num_to_count[num2] = 2;
            };
        }
        vector<int> intersection;
        for (auto [num, count] : num_to_count) {
            if (count == 2) {
                intersection.push_back(num);
            }
        }
        return intersection;
    }
};
```
#### 感想
```text
mapへ追加するところをnum1,num2まとめてできないか
ほかの解法がないか
O((N + M) log N)
```
## STEP2
### プルリクやドキュメントを参照
- setを利用している解法が多かった。

```cpp
class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
        unordered_set<int> nums1_sorted_and_not_duplicated(nums1.begin(), nums1.end());
        unordered_set<int> processed;
        vector<int> intersection;
        for (int num2 : nums2) {
            if (nums1_sorted_and_not_duplicated.contains(num2) && !processed.contains(num2)) {
                intersection.push_back(num2);
                processed.insert(num2);
            };
        }
        return intersection;
    }
};
```
#### 感想
```text
mapを使う必要はなかった。
n回出現した場合、などの条件であればmap使うべきか
O(N + M) 
```
- num1,num2をまとめて処理
```cpp
class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
        sort(nums1.begin(), nums1.end());
        sort(nums2.begin(), nums2.end());
        int index1 = 0, index2 = 0;
        vector<int> intersection;
        while (index1 < nums1.size() && index2 < nums2.size()) {
            if (nums1[index1] == nums2[index2]) {
                intersection.push_back(nums1[index1]);
                while (index1 + 1 < nums1.size()  && nums1[index1] == nums1[index1 + 1]) {
                    index1++;
                }
                while (index2 + 1 < nums2.size()  && nums2[index2] == nums2[index2 + 1]) {
                    index2++;
                }
                index1++;
                index2++;
                continue;
            }
            if (nums1[index1] > nums2[index2]) {
                index2++;
                continue;
            }
            if (nums1[index1] < nums2[index2]) {
                index1++;
                continue;
            } 
        }
        return intersection;
    }
};
```

#### 感想
```text
まとめられはしたがsetの解法のほうが見やすくわかりやすいと思った
if elseでつなげるほうが分かりやすい人もいるか
こちらのほうが早く動く
```
